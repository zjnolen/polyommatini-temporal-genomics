These notebooks contain the code used to perform statistical analyses and generate figures and tables for our manuscript. These notebooks largely take in population genetic analysis outputs as input. If you’re looking for code for processing the genomic data and producing population genetic metrics, most of that is processed by the Snakemake pipeline found in the analyses/workflow folder.

The notebooks are:

  • IBS aligner testing - which covers the identity by state similarity to the reference tests for vg vs bwa aln.
  • Genetic diversity, inbreeding, and differentiation - which covers heterozygosity, inbreeding coefficients, pi, and FST.
  • Population Structure - which covers the PCA and admixture plotting.
  • Putatively deleterious mutation burden - which covers calculation and plotting of putative deleterious mutation burden.
  • Additional Polyommatini species - which covers the estimation of heterozygosity change for the non-focal species.
  • GONE effective population sizes - which covers plotting the GONE inferred demographic histories.
